
<h1 align="lining">🌱 Planto</h1> 


An iOS app that reminds you to water your plants.

---

## ✨ Features

- Add, edit, and delete plants
- Check off plants you watered, with a progress bar
- "All Done" screen when every plant is watered
- Watering reminders (local notifications)
- Light and dark mode
- Adaptive app icon (Icon Composer)

---

## 🛠 Built With

| Tool | Used for |
|------|----------|
| SwiftUI | The screens |
| MVVM | Organizing the code |
| @Observable | Updating screens when data changes |
| UserNotifications | Watering reminders |
| Icon Composer | The app icon |

---

## 📁 Structure

| Folder | Files |
|--------|-------|
| **Models** | `PlantReminder` |
| **ViewModels** | `ReminderStore` |
| **Views** | `onboarding 1`, `SetReminderView`, `MainPageView` |
| **Services** | `NotificationManager` |

---

## ▶️ Run

1. Open the project in **Xcode**
2. Choose an iPhone simulator
3. Press **⌘R**
